# Kursus-Kita

## Scheduled feature rollout

The `main` branch receives one feature commit every two hours from
2026-11-19 20:00 UTC+8 (12:00 UTC) through the
[`scheduled-history`](https://github.com/TeguhSilitonga/Kursus-Kita/tree/scheduled-history)
branch. GitHub Actions requires `contents: write`; repository branch protection
must allow the workflow to push to `main`. GitHub may delay scheduled runs.
